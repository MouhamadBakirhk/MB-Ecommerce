# AI Ecommerce Bot

An AI-powered ecommerce assistant built using Laravel, JavaScript, and Flask.

## Features

* AI chatbot support
* Product recommendation system
* REST API integration
* Dynamic frontend interactions
* Backend authentication and routing

## Technologies Used

* Laravel
* JavaScript
* Flask
* Python
* MySQL

## Installation

Clone the repository:

```bash id="gm7t9c"
git clone https://github.com/your-username/ai-ecommerce-bot.git
```

Install Laravel dependencies:

```bash id="u6e2xp"
composer install
```

Install JavaScript dependencies:

```bash id="i8p5la"
npm install
```

Install Python dependencies:

```bash id="zy4n1b"
pip install -r requirements.txt
```

Run Laravel server:

```bash id="nn5x8m"
php artisan serve
```

Run Flask API:

```bash id="kd4v3q"
python ml_ecommerce_bot.py
```
